# BWT901 数据链路审阅（2026-07-28）

## 结论

IMU Plot 使用 `Raw` 数据。此前 Plot 顶部的 `RMS` 是对当前可视窗口统一计算的
统计量，不代表 IMU 曲线经过 RMS 变换。审阅后，非 EMG 的状态指标已改为
`Current / Min / Max`；EMG 仍显示 `Peak / RMS`。

## 数据链路

1. BWT901 decoder 按 demo 解析 `55 61 + 9 × Int16 little-endian`。
2. 加速度按 `raw / 32768 × 16 g` 换算。
3. 角速度按 `raw / 32768 × 2000 deg/s` 换算。
4. 角度按 `raw / 32768 × 180 deg` 换算。
5. 与 demo 一致，换算值保留三位小数。
6. Source 保存 `sequence`、九个物理量和共享时钟下的主机 BLE 通知接收时间。
7. CaptureStore 为 Plot 提供最近窗口，同时原样保留完整行用于保存。
8. CSV Writer 不做滤波、RMS、插值、重采样或归一化。

`Robust Scaling` 只决定 Y 轴范围。Plot 超过 1600 点时使用 min/max 抽点，这只
影响显示，不影响 CaptureStore 或 CSV；本次 IMU 约 10 Hz，在 5 秒窗口内不会
触发该抽点。

## 两次实验检查

- `102341`：5737 行，约 577.7 秒，序号连续；三轴加速度模长均值约 1.0067 g。
- `103452`：4326 行，约 435.6 秒；Pause 期间不入库造成序号跳跃；三轴加速度
  模长均值约 1.0173 g。

加速度、角速度和角度均在协议量程内。动态加速度峰值可能来自实验运动或冲击，
仅凭保存文件不能判为异常。截图中 Accel X 约 0.995 g，符合重力主要落在 X 轴
时的静态表现。

## 精度边界与建议

当前实现与 demo 一致，但换算时三位小数舍入且未保存原始 Int16。如果以后进行
高精度惯导积分、重新标定或误差模型研究，建议在不破坏现有物理量列的前提下追加
raw 列，或把舍入推迟到显示/导出层。BWT901 当前没有设备时间戳，约 10 Hz 的
`time_s` 包含 BLE 与主机调度抖动；严格同步或高精度积分应另行设计。
